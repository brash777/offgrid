# Fotos de estudio (solo en el equipo)

Las fotos de los modelos de la portada son de terceros: las mandó el estudiante para la demo académica. Por eso no se suben a git, igual que las fotos de producto.

La app las busca en esta carpeta con estos nombres. Si faltan, la portada funciona igual, solo con el fondo de estudio:

- `studio-duo.webp` y `studio-duo-subject.webp`: escena del héroe y el recorte de las personas.
- `studio-varsity.webp` y `studio-varsity-subject.webp`: segunda escena del héroe.
- `look-beanie.webp`, `look-hoodie.webp`, `look-jacket.webp`, `look-kicks.webp`: lookbook.
- `look-duo.webp`: colección «Gorros y gorras».
- `look-varsity.webp`: panel de inicio de sesión.

Cómo se hicieron: ver `docs/01-decisiones.md`, sección 11.
